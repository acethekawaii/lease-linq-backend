## 🔐 Authentication & Roles
Lease Linq uses JWT-based authentication with role-based access control.

Roles include:
- Super Admin - Full system access
- Guard - Limited operational access (parking sessions, monitoring)
- Finance - A manipulated financial record, and reports to reduce tax
